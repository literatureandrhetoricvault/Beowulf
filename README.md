# Beowulf: The Hero's Journey — GitHub Pages

## Deploy
1. Create a **public** repository on GitHub.
2. Upload `index.html` and `.nojekyll` to the repository's root. (Or upload all files in this ZIP directly into the repository root.)
3. Open repository **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/ (root)`, and save.
4. Open the Pages URL displayed by GitHub when it finishes publishing.

Do not open the GitHub source-file preview; open the **GitHub Pages** site.

## Saved student progress
- The game saves answers, first-attempt records, scores, writing, and section/chapter state automatically using browser `localStorage`.
- Returning to the **same GitHub Pages URL** in the **same browser profile on the same device** shows **RESUME SAVED JOURNEY** on the opening screen.
- Students can close the tab and reopen that URL without restarting the cinematic introduction.
- **START FROM THE BEGINNING** intentionally erases that browser's saved Beowulf session.
- Browser private/incognito mode, clearing site data, or switching devices/browsers will not preserve local progress.
- This is **not cloud sync**. Student progress is not transferred between devices and is not sent to a teacher. Ask students to download their final accuracy report.
- Do not change your repository's published URL during the assignment. The save is tied to that website origin.
- For many students on a shared browser profile, local saves can overwrite one another. Students should use individual school browser profiles/devices.

## Hosting and file size
- `index.html` contains embedded assets; no external fonts, images, or audio are required by this package.
- The only game asset is `index.html`. It is well below GitHub's 100 MiB per-file limit and the 1 GiB GitHub Pages published site limit.
- Keep the file named `index.html` and placed at the repository root.

## Testing saved progress
1. Open the GitHub Pages URL in regular Chrome.
2. Register, complete part of a reading/checkpoint, and type a partial analysis where available.
3. Close the browser tab.
4. Reopen the identical URL and select **RESUME SAVED JOURNEY**.
5. Verify the chapter, question state, first-attempt scores, and response are still there.

This build incorporates the four developed sections and the optional warrior, ship, Grendel, and dragon brain breaks. Arcade scores do not affect academic grades.
